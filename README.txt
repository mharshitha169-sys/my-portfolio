MY PORTFOLIO WEBSITE

FILES
- index.html    : Home page
- resume.html   : Resume page
- bio-data.html : Bio-data page
- style.css     : Styling for all pages
- script.js     : jQuery interactions

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted my-portfolio folder in VS Code.
3. Recommended: install the "Live Server" extension.
4. Right-click index.html and select "Open with Live Server".
5. You can also double-click index.html to open it in a browser.

BEFORE SUBMITTING
- Replace "Your Name" and other placeholder information with your own details.
- Update education, project, and contact information.
- To enable the resume download button, place your actual PDF in this folder and name it resume.pdf.
- The jQuery CDN requires an internet connection for the welcome button and mobile menu.
